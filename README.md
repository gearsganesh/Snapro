# GEARS SNAPRO

GEARS SNAPRO is a browser-based photo editing workspace developed for the GEARS Motortune digital ecosystem.

## Features

- Exposure and light adjustments
- Contrast, saturation, warmth and tint controls
- Highlights and shadows
- HSL color mixer
- Crop, rotate, straighten and flip
- Local selective adjustments with brush masks
- Histogram and before/after comparison
- JPG export

## Development

Prerequisites: Node.js

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

SNAPRO is intended to run as a standalone application at `snapro.gearsmotortune.com`.
